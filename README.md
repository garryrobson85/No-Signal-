# No Signal
### Reality Competition Simulator

A fully-featured Survivor-style reality competition simulator. Cast contestants, configure tribes, run challenges, reveal votes, and generate episode scripts — all in your browser, no install needed.

**[▶ Play Now](https://garryrobson85.github.io/No-Signal-)**

---

## Features

- 🎮 Full season simulation — challenges, alliances, idols, tribal council, jury finale
- 📜 Episode screenplay generator with host character and act structure  
- 🗓️ Tribe History tracker — colour-coded placement timeline
- 👤 Player Profiles — full per-player stats and season history
- 🕸️ Relationship Web — live visual graph of bonds and rivalries
- 📷 Custom character photos — upload your own cast images
- ✨ AI dialogue via Gemini — unique confessionals and exit speeches
- 💾 Save / load / export seasons
- 🌙 Dark mode

## How to play

Just open the link above. No account, no install, no server needed.

To enable AI-generated dialogue:
1. Get a free API key at [aistudio.google.com](https://aistudio.google.com)
2. In the game, go to **Setup → General Settings → AI Dialogue**
3. Paste your key — it stays on your device only

## Hosting your own copy

1. Fork this repository
2. Go to **Settings → Pages → Source: main branch**
3. Your copy will be live at `https://YOUR-USERNAME.github.io/no-signal`
